# AQNIWA JARVIS

## الأوامر داخل التطبيق
- `/بحث موضوع البحث`: يجلب حتى 6 نتائج من DuckDuckGo HTML ويلخصها نموذجك مع الروابط.
- `/إنشاء وصف المشروع` أو `/مشروع وصف المشروع`: ينشئ ملفات مصدر عامة ويجمعها في ZIP داخل Downloads.
- `/تطبيق وصف التطبيق`: ينشئ مشروع Android كامل بـ Kotlin وJetpack Compose، مع ملفات Gradle وGitHub Actions لبناء APK.

## بناء APK عبر GitHub Actions
أضف هذا المشروع إلى مستودع GitHub:
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع محتويات هذا المجلد إلى الفرع `main` (يجب أن يكون مجلد `.github` ضمن الملفات).
3. افتح تبويب Actions في المستودع.
4. اختر `Build AQNIWA JARVIS APK` ثم `Run workflow`، أو ادفع commit جديداً إلى `main`.
5. بعد نجاح المهمة افتح تشغيل workflow ونزّل Artifact باسم `AQNIWA-JARVIS-debug-apk`.
6. فك ضغط Artifact، ثم ثبّت `app-debug.apk` على هاتف Android واسمح بالتثبيت من هذا المصدر عند طلب النظام.

البناء يتم على خوادم GitHub Actions، وليس داخل الهاتف. لا يحتاج هذا المسار إلى بطاقة دفع عادةً ضمن حدود الاستخدام المجاني المتاحة للحساب، لكن GitHub قد يطبق حدوداً أو سياسات تتغير حسب الحساب.

## إعداد التطبيق
أدخل API Key وBase URL واسم النموذج داخل شاشة المحادثة. البحث يحتاج الإنترنت، وإنشاء الملفات وتلخيص البحث يحتاجان API صالحاً.

## حدود النسخة
- ناتج `/إنشاء` ملفات مصدر ZIP، وليس APK تلقائياً.
- سير العمل يبني APK التطبيق نفسه، ولا يحوّل كل مشروع يولده JARVIS إلى APK.
- هذا APK من نوع debug وغير موقّع كتطبيق إنتاج للنشر في المتاجر.
- لم يتم تنفيذ بناء فعلي في بيئة التطوير هنا؛ يجب تشغيل GitHub Actions للتأكد من نجاح التجميع.


## إنشاء تطبيق Android من داخل JARVIS
اكتب داخل المحادثة:
`/تطبيق لعبة رعب بثلاث مراحل وأزرار تحكم وشاشة بداية`

سيحفظ JARVIS مشروع Android في Downloads بصيغة ZIP. ارفع محتوياته إلى GitHub، ثم افتح Actions وشغّل `Build generated Android app` لتنزيل APK.
مهم: لا يوجد بناء APK محلي تلقائي على الهاتف. GitHub Actions هو الذي ينفذ البناء، وقد يحتاج الكود الذي ولّده النموذج إلى إصلاح إذا لم يكن متوافقاً مع Compose أو Gradle.
